# Mausbot proxy access

The browser state, screenshot, browser control, browser-engine install and file upload routes proxy to capabilities on the application host. They are intentionally public for the owner's demonstration deployment: no sign-in or administrator lookup is performed. This includes viewing the host desktop and browser, operating browser tabs, installing the browser engine and uploading files.

The former standalone password login and Supabase administrator gate are removed from the public demo path. The public page and its proxy-backed capabilities share the same access level.
