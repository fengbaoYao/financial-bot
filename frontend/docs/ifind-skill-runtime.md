# Financial Bot 的同花顺 Skill 运行说明

本项目通过 `requirements_api.txt` 安装固定版本的 `tonghuashun-ifind-skill`，由应用内 iFinD 适配器调用其自然语言路由与令牌续期代码。部署时需让后端环境能够安装该依赖；不依赖 Mac 用户目录下的 Skill 安装位置。不要将令牌写入仓库或日志。

服务端通过受保护的环境变量配置 `IFIND_ACCESS_TOKEN`；可另配置 `IFIND_REFRESH_TOKEN`。当 access token 缺失或被 iFinD 以 401 / -1301 拒绝时，若配置了 refresh token，服务端会调用 Skill 的换取接口并重试一次。换取成功的令牌仅缓存在本进程内，重启后重新从部署环境读取；续期失败会交回原有备用流程。服务进程需要重新加载环境变量才能看到配置变更。

Bot 研究对常见中文股票、财报、公告、指数等问题和部分英文关键词，在执行研究前尝试一次 iFinD 智能查询；不限制后续工具。查询失败、额度不足或结果为空时，记录缺口并继续现有流程。对单标的行情/公司基本面类问题，prepare_tools 会硬性优先 ifind_smart_query：未调用前只暴露该工具；成功后继续屏蔽 get_stock_analysis 等备用行情/基本面工具；仅当同花顺返回 unavailable 时才放行备用源。技术信号类、多标对比、投资者简报、个人持仓/记忆类问题不走硬门禁。该问题识别结合关键词、证券代码和 Skill 本身的常见别名，仍不能覆盖所有自然语言；包含个人持仓、交易、账户或记忆写入信息的原始问题不会自动发送给 iFinD。多美股代码的比较暂不作为单只股票查询，会继续原有流程。Work 使用智能研究的路径可复用查询入口，既有行情页面仍使用原 iFinD 适配链路。不得把这些规则描述成所有问题都已接入。

对实时行情，若上游路由把明确的近一月行情识别成实时价，会按自然月日期范围尝试 iFinD 历史行情；其他无法可靠解析的历史请求会拒绝实时价并使用既有流程；若报价为空也不会标作成功。证据显示来源为 iFinD，但智能查询未能从返回中可靠提取统一报价时间时，时间口径标记为待核实，不将取数时间当报价时间。

服务端部署后建议先通过一次公开股票小样例验证：同花顺优先事件、实际返回和来源、令牌续期、失败后的备选来源以及无结果时的缺口。不要使用真实资金、持仓或个人信息作为验收数据。
